# Git в VS Code

## 3 удобных вещи в VS Code
1. Визуальный diff — сразу видно, какие строки добавлены/изменены/удалены.
2. Встроенный редактор merge-конфликтов — кнопки «Accept Current / Incoming / Both».
3. GitLens — показывает автора и дату каждой строки прямо в редакторе.

## 1 вещь, которую удобнее делать в терминале
- Интерактивный rebase (`git rebase -i`) — в VS Code его нет, а в терминале легко squash/fixup коммиты.
